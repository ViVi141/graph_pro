- 从 Shaders_5_0_PP.shdc 提取 PSNormalMap...（此处指 tonemap）反汇编，确认 cbuffer 布局与 43 条指令

## 2026-10-22 04:25 深度->AO 阶段结论

### 已建成
- Present pass 深度捕获：`depth srv DIRECT 1920x1080 fmt 44`，零拷贝（直接在游戏自己的 R24G8_TYPELESS 纹理上建 SRV），`builds=2` 稳定。
- 深度候选规则：只收尺寸等于后缓冲的 DSV；单采样优先于 MSAA(2x)，后者作兜底。
- 离线调参链路：第 600/1200 帧 dump `GP_depth_<n>.raw` + `GP_color_<n>.raw`（1920x1080 packed），配合 `tools/ao_preview.py`、`tools/ao_contact.py` 可在 numpy 里复现 AO 并出图，不必反复重启。

### 实测数据
- Arma 深度分布：天空精确 1.0（占画面 12–21%）；底部 20% 对应 9–14 m；中部 27–87 m。
- 24 位精度在 d>0.999 时崩塌：相邻像素的 `1/(1-d)` 可差数倍，任何"相对深度比"指标在远场都会失真。

### 四种 AO 方案及失败原因
| 方案 | 结果 | 原因 |
|---|---|---|
| 相对深度差累加 | 天空和云全黑 | d→1 处精度崩塌，occ 爆表 |
| 米制距离累加 | 地面全黑 | 24 个采样点直接相加 |
| 地平线式 + 深度法线 | 物理正确但不可见（mean 0.92） | 掠射面上 max cosA=0.0027，山谷本就几乎不遮挡天空 |
| 双尺度差分（0.8 m / 4 m） | 仍不可见，且压暗灌木 | 差分仅 0.0094；枝干密集体自身多尺度都暗 |

**结论：Arma 已在跑 SSAO（其终段 shader 已被我们替换过），在只有深度、没有 G-buffer 法线的条件下，二次 AO 是结构性冗余，只会把植被压成黑块。已关闭（`GP_present.txt` mode 2），代码保留待有法线后重启。**

### 天空"发黑"排查结论
- 现象：画面 12–25% 的纯黑像素集中在天上。
- 逐项排除：AO（天空 d=1.0 直接跳过）、环境光注入（`GP_amb.txt` 改 0 0 后天空无变化）。
- **真因：`mission/init.sqf` 第 21 行 `setDate [2035, 7, 12, 18, 10]` —— 18:10 黄昏，逆光云本就接近全黑。**不是 bug。

### 下一步
1. 曝光接管：`Hook_Unmap` 已加常量缓冲尺寸日志，用于定位 `PSCB_PostProcess`（cb13）并钳制 `c[37].z` 自动曝光，目标是拉开室内外对比。
2. 接触阴影需要 G-buffer 法线或物体变换，属 B 档（D3D12 共享 + 自建 BVH）范畴。
## 2026-10-22 05:05 镜面注入：实测判定为负收益，已关闭

### A/B 方法
逐帧抓图（`GP_shot_*.rgb`），两帧像素完全对齐（最优位移 dx=0 dy=0），差异全部来自 `GP_spec.txt` 的开关。

### 逐区域差异（0-255，平均绝对差）

| 区域 | 平均差异 | >3/255 像素占比 |
|---|---|---|
| 集装箱 | 0.19 | 1.0% |
| 路面/裸土 | 0.35 | 1.9% |
| 石墙 | 0.86 | 2.0% |
| 天空/云 | 1.03 | 6.5% |
| 草丛植被 | 2.79 | 14.3% |

### 结论

注入的筛选条件是 `specular == 0`，而实测表明：

- **金属/涂装物体（集装箱）本来就有游戏写好的镜面值**，因此被跳过，差异仅 0.19；
- **草叶、云层**这类材质本来镜面为 0，被我们塞入 F0，成为差异最大的区域（2.79）。

也就是说：`specular == 0` 是美术的“这块该是哑光”的**明确意图**，不是“缺数据”。覆写它等于在草和云上制造本不该有的高光，
并且因为引擎没有法线过滤与粗糙度，草叶上出现逐像素镜面走样（闪烁噪点）。

物理正确的 F0 数值（4%、无色）实现本身没错，错的是**作用对象的选择**。已把 `GP_spec.txt` 改为 `0 0` 永久关闭。

### 附带发现

- 材质常量（PSCB_Object1）里的 `diffuse` 在 HDR 空间，观测值 0.65–3.24，**超过 1.0**；旧方案 `diffuse × 0.12` 因此会得到 0.39 这类远超物理 F0 的高光。
- 游戏材质定义确实以文本形式存在于 PBO（196 个 PBO 中共 2643 个 `.rvmat`），但本作的 PBO 容器不是标准布局（条目偏移全为 0、数据区非文本），解包需要额外的格式逆向；**运行期数据已足以定论，无需解包**。
## 2026-10-22 05:20 三方对比：原版 / 原版+游戏调色 / 我们的注入

同机位（任务内算出的固定视角，像素对齐 dx=0 dy=0），仅切换注入与任务内 ppEffect。

| 指标 | 原版 | 原版+游戏 ColorCorrections | 我们的注入 |
|---|---|---|---|
| 平均亮度 | 0.6491 | 0.8533 | 0.5652 |
| 对比 σ | 0.1778 | 0.1425 | **0.2267** |
| 锐度（拉普拉斯方差） | 0.0278 | 0.0306 | **0.0407** |
| 暗部占比 | 0.3% | 0.1% | 2.6% |
| 暗部 p05 | 0.380 | 0.567 | **0.225** |
| 饱和度均值 | 0.056 | 0.025 | **0.081** |
| 过曝占比 | 12.35% | **25.90%** | 15.39% |
| 与本注入帧的整帧差异 | 21.63 | 72.46 | — |

### 结论

1. 游戏自带的 `cold_highContrast` 预设**没有**复现我们的观感：它把画面提亮（0.649→0.853）、压低对比（0.178→0.143）、饱和减半（0.056→0.025），过曝翻倍到 25.9%。
2. 该预设是我们早先为“冷色高对比”写的，目标不是匹配本注入，因此这**不能证明引擎做不到**；但同等工作量下，游戏内联调得到的结果明显更差。
3. 逐通道曲线检验（前一轮）：单条全局曲线可解释大部分差异，残差 4.7–5.7/255，18–26% 的像素偏差 >8 —— 说明我们的改动**约等于一条带饱和度的 S 曲线**，属于“同一类工具”。
4. 我们的高光并未被救回（“救回”像素 0.01%），反而多吹 4.4%。此前“ACES 保留高光层次”的说法**不成立**。
5. 真正无法用游戏内选项替代的只剩两项：**自动曝光上限钳制**、**环境光缩放/色温**。

### 若要彻底定案

再写一个以匹配为目标（亮度≈0.80、对比≈1.35）的 ColorCorrections 预设跑一次；若其指标逼近 0.5652/0.2267/0.081，则 tonemap 替换可删除，只保留曝光与环境光两项。
## 2026-10-22 05:24 “以匹配为目标”的游戏内调色：失败（定案）

按我们自己的指标反推参数：`brightness 0.87`（本意：0.649→0.565）、`contrast 1.30`（本意：σ 0.178→0.227）、不染色、不去饱和。

| 指标 | 原版 | 原版+CC(匹配版) | 我们的注入 |
|---|---|---|---|
| 平均亮度 | 0.6488 | **0.6992**（本应更暗） | 0.5652 |
| 对比 σ | 0.1777 | **0.1596**（本应更高） | 0.2267 |
| 锐度 | 0.0278 | 0.0275 | **0.0407** |
| 饱和度 | 0.056 | 0.050 | **0.081** |
| 过曝占比 | 10.96% | 0.11% | 15.39% |
| 与本注入的综合偏差 | — | **31.0%** | — |

### 结论

1. 游戏的 `ColorCorrections` **没能**逼近我们的结果：目标变暗、变硬，实际变亮、变软，四项指标全部走反（综合偏差 31.0%，比原版的 24.8% 更差）。
2. 参数语义与文档假设不一致：`brightness 0.87` 得到更亮的画面，`contrast 1.30` 得到更低的对比。要拟合需要迭代搜索，而每轮都要重跑任务。
3. 两项属于**工具能力缺失**，不是调参问题：
   - 没有提高饱和度的参数（本版即使不染色，饱和仍从 0.056 降到 0.050）；
   - 锐度完全不变（0.0275），说明它只在既有 LDR 上做映射，无法产生我们那种色调分离。

### 对“是不是造轮子”的最终回答

**是同一类工具，但实测不能替代。** 我们的 tonemap 替换带来的是游戏内调色链路做不出来的结果（一次针对性调参即失败告终），
而真正独有、游戏无任何对应开关的仍是两项：**自动曝光上限钳制**、**环境光缩放/色温**。

保留 tonemap 替换；若日后要精简，优先考虑砍掉它与 SSAO 替换，保留曝光与环境光。
