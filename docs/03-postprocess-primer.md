# 后处理入门：它到底在干什么（任务 3）

> 给"不懂渲染"的人看的版本。看完你应该能回答：为什么改一个 tonemap 比换 4K 贴图更"像照片"。

---

## 1. 一句话

**后处理 = 场景已经画完之后，对"整张图"统一做的处理。**

引擎先把 3D 世界画成一张 **HDR 图**（高动态范围：数值可以远大于 1，太阳可能是 900，白墙 0.8，阴影 0.01），然后显示器只认 0~1。
把"能到 900 的图"压进"只能显示 0~1 的屏幕"，还要让它看起来像人眼/相机看到的——**这一整套工序就是后处理**。

类比：
- 相机拍完照，先存 RAW，再由 ISP/后期软件"显影、压高光、调色、加锐"；
- 后处理就是 A3 的"ISP + 显影 + 调色"。
- **没有后处理，你看到的就是一张没显影的 RAW：要么死白，要么死黑，要么灰得像蒙了层纱。**

---

## 2. 为什么非它不可

因为**真实世界不是线性的**：

| 场景 | 真实亮度比 | 屏幕能给 |
|---|---|---|
| 晴天窗外的天空 vs 室内墙角 | 约 1000 : 1 | 约 100 : 1 |

如果直接把 HDR 值截断到 0~1（Clamp），窗外天空、太阳、车灯、爆炸火光**全部变成一块死白**，没有任何层次。
如果整体压暗到能看见高光，室内就黑成一片。
**tonemap（色调映射）**就是干这个的：把巨大的亮度范围"弯"进屏幕，同时保留高光和暗部的层次。

![tonemap 对比](demo/tonemap-demo.png)

上图四格是同一张 HDR 图（示意，非 A3 实拍）：
- **Clamp**：太阳/天空直接切成纯白，没有颜色、没有细节——这就是"游戏感"的一大来源；
- **Reinhard**：高光有滚降了，但整体发灰、发闷（A3 默认档位之一就是这个味道）；
- **ACES filmic**：高光平滑过渡、亮部还留着颜色，暗部不死黑——"照片感"立刻出来；
- **ACES + bloom**：光源开始"发光"，亮的东西有了体积感。

一张图里唯一的区别就是**几个数学公式**，但观感差了一个世代。

## 3. A3 的后处理链（按 shader 名单整理的大致顺序）

```
场景渲染(HDR) → 深度/法线
   → SSAO（环境光遮蔽）
   → 景深 / 动态模糊
   → Bloom（泛光）
   → 亮度统计 / 自动曝光
   → Tonemap（色调映射）★
   → 调色（ColorCorrections / LUT）
   → 颗粒 / 色差 / 暗角
   → 抗锯齿（SMAA / FXAA）
   → UI
```

顺序很重要：**先 AO 再 tonemap**（AO 是场景属性），**先 tonemap 再调色**（调色是对"显示值"调）。

---

## 4. 每个 pass 是干什么的（以及关掉会怎样）

| Pass | 作用 | 关掉/调弱 | 调强 |
|---|---|---|---|
| **Tonemap** | 把 HDR 压进屏幕 | 高光死白、颜色断层 | 更"电影"，但可能发灰 |
| **Bloom** | 亮处向外溢光 | 夜景灯光像贴纸，没有体积 | 糊、发雾、对比下降 |
| **SSAO** | 缝隙/接触处的暗部 | 物体像"浮"在地上 | 脏、边缘发黑 |
| **SMAA/FXAA** | 抗锯齿 | 满屏锯齿、树叶闪烁 | 画面变软、细节丢失 |
| **调色 (CC)** | 统一色调/对比/饱和 | 原色，偏"生" | 风格化，过量就假 |
| **Film Grain** | 胶片颗粒 | 干净但"数码味" | 噪、脏 |
| **色差 (ChromAber)** | 镜头边缘色散 | 无 | 廉价"故障风" |
| **暗角 (Vignette)** | 四角压暗 | 平 | 过重像偷窥 |
| **DOF** | 景深虚化 | 全清晰，像监控 | 过度=看不清 |
| **动态模糊** | 运动拖影 | 更"游戏"、更清晰 | 晕、糊 |
| **HDRColorLimit** | 高光裁剪 | 溢出/闪烁 | 更闷 |
| **Caustics** | 水下光斑 | 水面死板 | 过亮 |
| **SSSM** | 次表面散射（皮肤/植被透光） | 塑料感 | 蜡感 |

---

## 5. 为什么说这是 A3 "画面感"的命门

1. **A3 的 PP 是 2013 年的调校**：高光硬切、对比偏冲、雾感重、AO 弱、bloom 容易糊成一片。这是"Arma 味"的主要来源之一。
2. **它作用于全屏**：改一个 pass，全地图、所有 DLC、所有 mod 同时变——**不需要动一个模型、一张贴图**。
3. **成本几乎为零**：你是在**替换**已有的全屏 pass，不是**新增**。对核显尤其重要（ReShade 叠加才是"新增"）。
4. **可逆、可迭代**：改坏了换回来；调参就是改几个数字。

**但要知道它的边界**：后处理是"调色师"，不是"摄影师"。
它改不了：材质怎么反光（rvmat）、光照怎么算（引擎）、阴影分辨率、LOD 跳变、模型精度。
所以"拟真"= **场景渲染（材质/光照）+ 成像（后处理）**，缺一半都不行。

---

## 6. 你该先动哪个（性价比排序）

1. **Tonemap**（`PSPostProcessGlowNewFinalFilmic`）—— 一步到位改变"整张图的性格"
2. **SSAO**（`SSAOFinal`）—— 让物体"坐"进世界
3. **Bloom 阈值**（`GlowNewBloomInitDownsample`）—— 夜景从"贴纸"变"光源"
4. 调色（`PsPpColors`）—— 最后再统一风格
5. 颗粒/色差/暗角 —— 收尾的"镜头语言"，少量即可

---

## 7. 一句话总结

**后处理不改变世界里有什么，只改变"你怎么看见它"。**
而这恰好就是"像不像照片"的差别所在——所以它才是投入产出比最高的那一层。
