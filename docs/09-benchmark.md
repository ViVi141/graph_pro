# 对标：现代写实游戏 / 真实照片 / 我们的画面

日期：2026-10-22　参考：UE5 官方文档（Virtual Shadow Maps）、Digital Foundry 对 UE5 作品的画面分析，以及通用的图像统计经验值。

---

## 一、技术能力对比

| 能力 | 现代写实 3A（UE5 世代） | Arma 3 原版 | 我们改后 |
|---|---|---|---|
| 全局光照 | Lumen / 硬件 RTGI，动态反弹光 | 无 GI，环境光常量 | 环境光常量 + 冷色偏移（近似） |
| 阴影 | 虚拟阴影贴图 / PCSS，接触处硬、远处软 | 固定核 PCF | 未改 |
| 环境光遮蔽 | GTAO / RT AO，含天空遮蔽 | SSAO（屏幕空间） | SSAO resolve 加强 |
| 反射 | SSR + RT 反射 | SSR（可开关） | 未改 |
| 材质 | PBR：粗糙度/金属度/法线贴图 | 有限 BRDF，rvmat 参数 | 补了电介质镜面 F0 |
| 抗锯齿 | TAA/TSR + 超分 | FXAA/SMAA/MSAA | SMAA + MSAA 8x |
| 大气 | 体积云、体积雾、光轴 | 简单雾 + 云层纹理 | 未改 |
| 色调映射 | ACES / AgX，统一色彩管理 | 自有 filmic 曲线 | 替换为 **AgX**（ACES 为备选；本表 2026-10-22 版写作 ACES） |
| 动态范围 | HDR 输出 + 眼睛适应 | SDR + 眼睛适应 | 曲线校准，仍受适应影响 |
| 植被 | 几何体 + 风场 + 半透明 | alpha 面片 | 未改 |
| 贴图 | 4K + 虚拟纹理 | PAA，受 textureQuality 限制 | 拉满 |

## 二、可测指标对比

| 指标 | 真实照片（经验区间） | 现代写实游戏 | A3 原版（实测） | 我们改后（实测） |
|---|---|---|---|---|
| 亮度 1% 分位 | 0.02 – 0.08 | 0.02 – 0.06 | **0.28** | **0.135** |
| 亮度 99% 分位 | 0.92 – 0.98 | 0.90 – 0.97 | 0.81 | 0.82 |
| 对比度 σ | 0.18 – 0.25 | 0.16 – 0.22 | 0.116 | **0.142** |
| 暗部占比（<0.35） | 10 – 25% | 8 – 20% | **0.1 – 3.3%** | **14%** |
| 暗部 R−B（色温） | −0.03 ~ −0.08 | −0.02 ~ −0.06 | **+0.03（反了）** | **−0.05** ✅ |
| 受光 R−B | +0.02 ~ +0.06 | +0.02 ~ +0.05 | +0.03 | **+0.045** ✅ |
| 微对比（路面 std） | 0.12 – 0.20 | 0.10 – 0.18 | 0.07 | 0.07（未改） |
| 平均饱和度 | 15 – 25% | 12 – 22% | 9 – 10% | 15% |

## 三、结论

### 已经补上的（色调/成像层）

- **动态范围**：暗部从 0.28 压到 0.135，暗部占比从 3% 提到 14%
- **色温关系**：从“阴影偏暖”纠正为“阴影偏冷、受光偏暖”
- **对比与饱和**：σ 0.116 → 0.142，饱和度 10% → 15%

这三项属于“成像”，是现代写实游戏和真实照片的**入场券**，但只是入场券。

### 仍然缺的（结构层，工具链够不到）

| 差距 | 现代做法 | 我们的限制 |
|---|---|---|
| **间接光** | Lumen/RTGI 让暗部有反弹光、颜色溢出 | 无 GI，环境光是常量，暗部只能整体调色 |
| **接触阴影** | 虚拟阴影贴图 / PCSS | 阴影是固定核 PCF，改不了算法 |
| **材质粗糙度** | PBR 粗糙度贴图，逐像素变化 | 只能改每材质的常量，做不到逐像素 |
| **微对比** | 4K 贴图 + 细节法线 + 污渍层 | 贴图已被 textureQuality 限制，且无细节层 |
| **植被** | 几何 + 风场 | alpha 面片，密度和体积都低 |
| **时间稳定** | TAA/TSR | 只有 SMAA，细高光会闪 |

### 一句话

**我们的画面现在在“色调正确”这一层达标了，但“光照正确”这一层还差一个数量级。** 前者靠替换后处理和改常量能到，后者需要 GI 和逐像素材质——那是重写渲染器的量级。
